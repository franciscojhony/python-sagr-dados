Configuração do Download

1. Planilha

Clique para escolher ou arraste o arquivo aqui
.xlsx, .xlsm ou .csv
Lendo a planilha… planilhas grandes podem levar alguns segundos.

2. Linhas a processar

A linha 1 é a primeira nota (o cabeçalho não conta). A linha final é incluída. Rode em lotes pequenos (ex.: 1–50, depois 51–100) para evitar bloqueio do site.

3. Pasta de destino

A pasta é criada se não existir. Notas já baixadas nela (<chave>.xml) são puladas.
Opções avançadas (pausas entre as notas)
Ao executar, uma janela do Google Chrome vai abrir sozinha. Não a feche e evite usá-la. Se aparecer a verificação anti-robô (Cloudflare), resolva você mesmo na janela — o programa continua depois.

Importar no SISGI

1. Pasta dos XMLs

O programa lê a data de emissão de cada XML e envia agrupando por mês (o SISGI só aceita notas do mês de competência). O que já foi enviado fica registrado no arquivo sisgi_importados.txt, nessa pasta.

2. Filtros

Vazio = importa todos os meses e todos os arquivos pendentes.

3. Sistema SISGI

O endereço padrão é o de homologação (hmg). Troque se for importar na produção.
Ao executar, uma janela do Google Chrome abre no SISGI. Faça o login você mesmo nela — o programa continua sozinho quando a lista de despesas aparecer (até 5 minutos). Ao final, um aviso aparece no Chrome: clique em OK (ou em Parar aqui) para fechá-lo.
